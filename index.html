Support

For help or language feedback, email hassan@fromhaz.com. Include your app version and iOS version when useful. Please avoid sending sensitive personal information or private translation history.

Using translation and audio

Translation requires iOS 18 or later and supported Apple language models. Speech recognition, translation and pronunciation voices can need separate system downloads. Prepare the required assets before relying on these features offline. The learning library and flash cards work without those downloads.

History can be deleted in the app. Microphone input is optional; typed and pasted input remain available. Enhanced/Premium pronunciation voices are downloaded through Apple Settings, with guidance in the app.
