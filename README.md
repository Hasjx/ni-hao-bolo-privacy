# Public privacy and support pages

These pages describe Ni Hao Bolo's actual local storage, Apple translation/recognition assets, optional microphone input, clipboard use and support email. English and Simplified Chinese text is included. They contain no review phone number, credentials, app source or analytics.

`privacy.html` is the privacy-policy page; `index.html` is support. A separate public policy-only repository can host these pages through GitHub Pages, following the owner's existing privacy URL pattern. The application repository stays private. Confirm the resulting HTTPS pages load before saving their URLs in App Store Connect or shipping the app's Settings link.
